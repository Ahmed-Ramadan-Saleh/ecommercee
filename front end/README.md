# 🛒 SHOP.CO - E-Commerce Platform

A full-stack e-commerce platform built using the **MERN Stack** (MongoDB, Express, React, Node.js).  
The project provides a modern shopping experience for users and a powerful admin dashboard for managing products, orders, and customers.

---

## 🚀 Features

### 🛍️ User Storefront

- Modern and responsive UI
- Light / Dark Mode support
- Product browsing and filtering
- Product details page
- Shopping cart functionality
- Secure checkout system
- User authentication (Login / Register)
- Order tracking

### ⚙️ Admin Dashboard

- Manage products (Create, Update, Delete)
- Manage customer orders
- View analytics and sales insights
- Manage users

---

### Frontend
